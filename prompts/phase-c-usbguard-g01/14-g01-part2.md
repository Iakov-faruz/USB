# פרומפט 15 — בדיקות התנהגות G-01 חלק ב` (Gate G-01 Tests Part 2)

## מטרה
איך לבדוק מקרי קצה והתנהגות לאחר הפעלה מחדש. המשך ישיר לחלק א`.

## קבצים צפויים
`docs/g01-report-part2.md`, `docs/g01-final-report.md`

## קריטריון אימות
בדוק שהדוח הכולל כולל סטטוס סופי (PASS/FAIL/UNVERIFIED).

## מה לומדים
איך לבדוק מקרי קצה והתנהגות לאחר הפעלה מחדש.

---

```text
PROMPT 15 — Gate G-01 Tests Part 2

LAB ENVIRONMENT ONLY.

Execute the following tests and document results:

1. Test: Rule precedence — add block rule, then allow rule, check which wins.
2. Test: Remove rule with current Rule ID (not cached ID).
3. Test: Behavior after daemon restart.
4. Test: Behavior after system reboot.
5. Test: What happens when IPC is unavailable.

For each test, record:
- Exact command sequence
- State before and after
- Exit codes
- Conclusion

Compile final G-01 report with PASS/FAIL for each test.
If any test fails, mark G-01 as UNVERIFIED and stop.
```

## משימות מפורטות

עבור את הבדיקות הבאות במעבדה בלבד:

1. בדיקה: קדימות כללים — הוסף כלל חסימה, אחריו כלל אישור, בדוק מי מנצח.
2. בדיקה: הסר כלל עם Rule ID עדכני (לא מזומן).
3. בדיקה: התנהגות לאחר הפעלה מחדש של הדמון.
4. בדיקה: התנהגות לאחר אתחול מערכת (reboot).
5. בדיקה: מה קורה כאשר IPC אינו זמין.

עבור כל בדיקה, רשום:
- רצף פקודות מדויק
- מצב לפני ואחרי
- קודי יציאה
- מסקנה

רכז דוח G-01 סופי עם סטטוס PASS/FAIL לכל בדיקה.
אם בדיקה כלשהי נכשלת, סמן את G-01 כ-UNVERIFIED ועצור.

## ערך החזרה

דוח G-01 סופי כולל סטטוס סופי. אין לטעון PASS אם בדיקה חובה חסרה.

## איסורים

- בדיקות אלה ירוצו בסביבת מעבדה מבודדת בלבד.
- אל תסמן PASS אם ראיות חסרות.
