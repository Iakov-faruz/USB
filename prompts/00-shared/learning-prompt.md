# פרומפט לימודי לאחר כל שלב

מסביר בעברית את המימוש שבוצע בשלב האחרון, כאילו הלומד בונה מערכת אבטחה אמיתית ולא רק מעתיק קוד.

חובה לכלול:

1. **מה הבעיה** — איזו בעיה הנדסית או אבטחתית נפתרה בשלב הזה.
2. **איך הפתרון עובד** — זרימת הנתונים והפעולות לפי סדר.
3. **הקבצים** — האחריות של כל קובץ ששונה.
4. **החלטות תכנון** — מדוע נבחר הפתרון ומה היו החלופות העיקריות.
5. **סיכונים** — מה עלול להשתבש ואיך הקוד מתמודד עם זה.
6. **בדיקות** — מה כל בדיקה מוכיחה ומה היא אינה מוכיחה.
7. **דוגמה** — תרחיש קונקרטי עם קלט, פעולות ותוצאה.
8. **שאלות לבדיקה עצמית** — שלוש שאלות קצרות לוודא הבנה.

לא לכתוב את כל הקוד מחדש. להתמקד בשינויים האמיתיים שבוצעו ובשורות החשובות להבנה. אם קיימת בעיה או מגבלה — לציין אותה במפורש.
