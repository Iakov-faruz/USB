# פרומפט 01 — תוכנית מימוש ומפת רכיבים

## מטרה
להפוך את ה-SRS לתוכנית עבודה מדורגת שניתן לעקוב אחריה, על בסיס ממצאי פרומפט 00 וה-SRS בלבד.

## משימה

הגדר את תחומי האחריות של הרכיבים הבאים, **בלי לכתוב עדיין את המימוש**:

- הגדרות ונתיבים.
- קודי יציאה.
- Logging ו-Audit.
- נעילות.
- כתיבה אטומית.
- Parsing ואימות קלט.
- זמן ואמינות השעון.
- USBGuard adapter.
- בדיקות G-01.
- מודל TTL ומצב.
- אישורים זמניים וקבועים.
- Reaper והתאוששות.
- CLI ו-TUI.
- פעולות מרובות.
- גיבוי ושחזור.
- ייבוא וייצוא.
- systemd ופריסה.
- תיעוד ובדיקות שחרור.

לכל רכיב ציין:
1. אחריות.
2. קלט ופלט.
3. תלות ברכיבים אחרים.
4. גבולות אבטחה.
5. בדיקות קבלה.
6. דרישות SRS רלוונטיות (מזהים אמיתיים מ-USB.md בלבד, לא ממציאים).

## איסורים

- אל תיצור שכבות או ממשקים ללא צורך ברור.
- אל תמציא מספרי דרישות.
- לא כותבים קוד מימוש בשלב זה.

## ערך החזרה

- תוכנית מימוש מדורגת עם responsible per component.
- רשימת החלטות הדורשות אישור לפני כתיבת קוד.
